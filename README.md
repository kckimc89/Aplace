# 세계 명소대백과 Stage 0.3 — 나라 이름표·사진 관광가이드

기존 Stage 0.2의 디자인, 101개국, 40개 명소 초안, 사진·검색·백업 저장키를 보존한 단계입니다.

- 나라별 완성 초록색 / 검색 검토 보라색 / 미완 흰색 / 점검 빨강 이름표
- 나라별 7개 분류 필터와 완성 카드 보기·감추기
- 명소 상세에서 사진과 함께 한국어 관광가이드 음성 낭독. 사진 한 장의 설명이 끝나면 다음 사진으로 이동
- 부모모드에서 확정된 사진별 가이드 설명 편집
- 음성은 iPad Safari의 Web Speech 음성합성 기능 사용. 실제 Safari 기기 검증 필요
- 사진 내용 설명을 지어내지 않으며, 사진별 설명이 없을 땐 명소 개요/사진 비교 안내를 읽습니다.
- 기존 명소 자료는 **검증 전 초안**입니다. 사진 후보 및 별칭은 검증 상태를 계승합니다.
