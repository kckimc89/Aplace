# 세계 명소대백과 Stage 0.9 PHOTO FIRST

Stage 0.8 앱을 기준으로 사진 검색 부분을 개선한 전체 배포 ZIP입니다. 기존 나라/카드/여행/부모모드/백업의 저장 키는 유지합니다.

## 주요 변경
- 위키데이터 식별번호 또는 위키백과 문서로 정확한 명소를 확인하고 위키미디어 공용 P373 분류 탐색
- 사진분류의 직접 파일 + 하위 분류 일부 탐색, 최대 130개 파일명 확인 후 1600px 사진정보 요청
- 부족한 사진은 별칭/문서명으로 검색 보충, 최대 48개 후보 표시
- 후보는 자동 승인되지 않으며, 부모가 정확성과 라이선스를 확인 후 개별 사진첩에 추가
- 1600px 미리보기로 iPad에 맞춘 트래픽 제어

## 제한 / 검증 안내
- 이 환경에서는 iPad Safari 및 외부 API의 실제 응답을 검증하지 않았습니다.
- 명소별 QID/Commons 분류가 없거나 잘못되면 이름 검색으로 대체됩니다.
- 기존 앱 기초자료는 5개국×8개(40개)이며, 추가 6개국×10개(60개) 확장은 별도 콘텐츠 작업입니다.
- Wikimedia URL은 인터넷 연결이 필요하며 후보의 초상권·라이선스·관련성은 자동 보장되지 않습니다.
- 배포 시 ZIP의 모든 파일을 GitHub Pages 저장소 루트에 올리세요.
