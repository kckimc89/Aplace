# 세계 명소대백과 Stage 1.9 — CARD MANAGEMENT

기준: Stage 1.8.2 업로드 ZIP. 기존 `landmarks-data` 및 IndexedDB 사진 보관함 유지.

- 부모모드: 카드 상태 해제(내용 보존) 및 복구
- 사진 후보 재검색 / 검색 후보 캐시 초기화 (기존 사진 보존)
- 직접 추가한 명소 완전삭제. 보관된 사진이나 여행기가 있으면 삭제 차단
- 기존 명소 추가/수정/설명 추가/사진 보관/전체 백업은 유지

**주의:** 카드 관리 기능은 백과의 기본 374개 명소 내용을 자동 검증하거나 사진 라이선스를 검증하지 않습니다. 기존 사용자 사진은 브라우저 IndexedDB에 있으며 ZIP 안에는 포함되지 않습니다. GitHub 공개 저장소에 올리는 개별 사진의 라이선스는 별도로 확인해야 합니다.
