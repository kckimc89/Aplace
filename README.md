Stage 2.2.3 기준 파일 유지. 나라 화면에서 부모모드를 켠 다음 「이 나라 자동보강 시작」. 기존 명소의 Wikimedia Commons 사진 후보를 탐색, 제목·크기·풍경 메타데이터 기반 최대 30장 자동 저장. 진행상태/일시정지/재시작 localStorage. 기존 사진, 순서, 설명, 여행기, 백업 기능 유지. 사진의 시각적 품질·명소 일치와 라이선스의 완전한 자동 검증 기능은 포함되지 않음. 새 나라의 명소와 설명 자동 생성 기능은 미구현. Safari 종료 중 작업은 수행되지 않음.
