# 세계 명소대백과 Stage 0.9 — 1차 확장 6개국 각 10개

Stage 0.8 아름다운 화면과 카드 기능을 그대로 계승했습니다.

## 현재 범위
- 프랑스·대한민국·일본·중국·이탈리아·스페인: 각 10개, 총 60개 명소 후보
- 기존 40개 + 28개 신규 항목 = 기초자료 68개 (기존 대만 8개 포함)
- 6개국의 이름표/분류/검색 별칭/개별 카드/나라 사진 여행
- 프랑스 관광가이드 전용 원고 보존; 다른 나라의 여행 안내는 명소별 설명을 바탕으로 첫 초안을 만듭니다.
- 신규 항목의 사진은 아직 온라인 검색 및 부모 확인 전이며, 자동 표시되는 위키 참고사진은 검증된 사진으로 간주하지 않습니다.
- 나라별 10개는 등록 후보 수이며 초록색 최종 검증 카드 10개를 뜻하지 않습니다.
