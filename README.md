# 세계 명소대백과 Stage 1.7 — STORY FIRST

기준: Stage 1.6 전체자료를 그대로 복사해 설명카드의 화면 구성 변경.

- 첫 화면: 큰 글씨(19~23px), 아이보리색 독서 화면, 기존 명소 설명 문단별 배치.
- 두 번째 화면: 기존 사진첩·후보 검색·사진 저장·출처정보.
- 후보 슬라이드쇼에 ‘이 사진을 사진첩에 저장’ 버튼 추가(부모모드). 저장은 원래와 같은 확인·압축·IndexedDB 흐름.
- 원래 374개 명소와 101개국, 사진 저장소 키, 백업 포맷은 변경하지 않음.
- 사진첩 사진과 이용조건 검증은 여전히 부모 확인이 필요.
- 개별 설명 내용 자체를 374개 모두 독립 재집필한 것은 아님; 원고의 정확성 추가 검토 필요.
