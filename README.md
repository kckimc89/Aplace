# 세계 명소대백과 Stage 1.0 — 검색기반 보강판

Stage 0.9 기능·사진·사용자 저장키 보존. 초기 명소 68개(핵심 6개국 60곳, 대만 8곳).

- 중국(특히 자금성)·이탈리아·스페인 중심으로 현지어·영어 별칭 확충. 기존 별칭 삭제하지 않음.
- 사진검색: 위키미디어 공용에서 영문/현지어/한국어 복수 검색어, 중복 제거, 제목 일치도·화질 기반 정렬, 최대 60개 후보.
- 검색어 하나가 실패해도 다른 별칭으로 계속 검색. 사진은 **부모 확인 및 라이선스 확인 후** 등록. 자동 검증/저장 아님.
- 자금성 사진이 즉시 자동 표시된다는 보장은 없음. 자금성 카드에서 「다른 사진 찾아보기」 실행하여 후보 확인.
- 네트워크 연결이 없거나 Commons API 제한이 있으면 사진 검색에 실패할 수 있음.
- 원래 저장자료와 프랑스 여행 연출을 보존. 여행 음성에서 반복적인 지시형 문구 일부 교체.

## 배포
명소대백과 전용 GitHub 저장소에 ZIP 내부 파일 전체 올리기. `?v=10-search` 로 캐시 갱신. 이전 버전 자료 백업 권장.
