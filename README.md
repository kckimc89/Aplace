## 새 기능
- 저장 사진첩 자동재생 (3/5/8초), 이전/다음, 고정 하단 조작창

- 후보사진을 체크해 여러 장 저장(요청별 실패 건수 보고)
- 기존 명소 추가/편집/초록색 카드 상태·사진 추가·설명·여행기 기능 유지
