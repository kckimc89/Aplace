# 세계 명소대백과 Stage 0.4 — 우선 15개국과 나라 사진 여행

Stage 0.3 소스와 디자인, 저장키, 사진, 검색·편집·백업 기능을 보존하며 확장했습니다.

- 나라 목록 기본 화면: 우선 15개국. `101개국 전체 보기`로 기존 101개국 탐색 가능. 나머지 국가 데이터 삭제 없음.
- 이미 준비된 명소 40개는 계속 **5개국 미검증 기초자료**로 남습니다. 나머지 10개국은 명소 검색/등록이 필요합니다.
- 나라 사진 여행 시범: 프랑스(에펠탑·몽생미셸), 대한민국(경복궁), 기존 사진을 중복 저장하지 않고 순서대로 재생.
- iPad TTS 음성·짧은 장소별 원고·전체화면 사진·자막·정지/이전/다음/닫기.
- 사진이 없는 나라는 `준비 중`으로 표시하며 허구의 사진 여행은 제공하지 않습니다.
- 이름/사진 정확성 검증과 실제 iPad 음성 동작은 계속 검증 대상입니다.

새 ZIP의 파일 전체를 **명소대백과** 저장소에 업로드하고 `?v=04-focus`로 엽니다. 기존 음식대백과 저장소에는 올리지 마세요. 업로드 전 백업 권장.
