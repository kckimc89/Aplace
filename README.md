# 세계 명소대백과 · Stage 2.1 PHOTO CURATION

기준: Stage 2.0 전체 파일. 101개국/374개 기본 명소 데이터 유지.

추가: 부모모드 > 명소 카드 > 다른 사진 후보에서 **✨ 좋은 사진 자동선정·저장**. 후보 제목, 크기, 가로 비율, 풍경 키워드, 중복 구도/장면 다양성을 기반으로 최대 30장을 추천하여 앱의 IndexedDB 사진첩에 차례로 누적 저장. 기존 사진, 사진 순서, 여행기, 설명 삭제 없음. 라이선스 메타데이터가 재사용 가능한 범주인 후보만 선별하며 원본 조건/명소 일치의 최종 검토가 필요함. 자동선정은 사진 실제 픽셀의 AI 영상 판독이 아니며 이미지 품질·정확성 완벽 보증 불가. 취소/중단 후 저장 완료분 보존, 통신 오류 발생 사진 별도 집계. 대량 저장 전 사진 포함 백업 필수. iCloud Drive 자동 저장 아님.

배포: ZIP 안의 파일 **전체**를 기존 GitHub Pages 저장소에 덮어쓰기 업로드하고 ?v=21-photo-curation 으로 접속. 부모모드를 켠 뒤 후보 검색을 완료해야 자동선정 버튼이 보임. 실제 iPad Safari/Wikimedia 연결 저장 동작은 사용자 환경에서 확인 필요.


Stage 2.2 PHOTO ORGANIZER:
- 부모모드 > 명소 사진첩 > '사진첩 정리'에서 전체 사진을 격자로 보고 순서 변경/대표사진/선택 삭제.
- 사진 순서만 IndexedDB albumSettings 별도 공간에 기록하므로 localStorage 전체 재기록을 피합니다.
- 사진 포함 백업에 albumOrders 포함, 이전 v2 백업도 복원 가능. 기존 사진 데이터와 설명은 유지.
- 다음 단계: 사진 미확보 명소의 검색·연결 정확성 개선.


Stage 2.2.1 BACKUP ALBUM ORDER RESTORE:
- 복원 중 대표사진이 먼저 기록되어 빈 사진순서가 만들어지고, 이후 순서 복원이 건너뛰어지던 결함 수정.
- 백업에 명소별 사진 순서가 있으면 현재 기기의 사진 순서를 해당 백업의 순서로 복원.
- 백업에 순서 항목이 없는 구버전 파일은 현재 사진 순서 보존.
- 사진 데이터, 명소 기록, 나의 여행기, 기존 저장소 키 변경 없음.
- 복원 후 사진순서 적용 명소 수 표시.
