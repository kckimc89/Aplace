# 세계 명소대백과 · Stage 2.2.3 (명소 목록 백업·복원 보강)

기준: Stage 2.2.2 101개국 378개 명소 전체판. 신규 한국 명소 4곳과 기존 사진첩 정리/순서/백업 기능 유지.

## 수정
- 사진 포함 백업 JSON에 **기본 명소 목록 378곳 전체(catalogEntries)** 포함. 사용자 추가 명소(edits.added)는 이전대로 포함.
- 복원 때 현재 앱의 기본 명소/이미 등록한 명소는 건드리지 않고, 백업에만 존재하는 기본 명소를 누락 명소로 가져와 통합합니다. 고유 ID 기준 중복 방지.
- 기존 Stage 2.2.2 백업은 기본 명소 전체를 포함하지 않아 과거 버전에서 네 명소가 누락될 수 있었음. 예전 백업에 없는 내용은 그 백업만으로 재생성할 수 없으나 **현재 ZIP의 기본 목록에는 한국 신규 4개 명소가 포함**됨.
- 사진, 사진 순서, 대표사진, 여행기 저장 기능은 유지. 이전 백업 형식 읽기도 유지.
- 백업 안내에 기본 명소 수와 직접 추가 명소 수를 명시, 복원 결과에 새로 가져온 명소 수 표시.

ZIP 압축 해제 후 **모든 파일** 업로드. `/?v=223` 접속하고 Stage 2.2.3 확인. 파일 앱의 예전 백업은 지우지 말고, 새 버전에서 **새 백업**을 먼저 생성하여 iCloud Drive에 보관하세요. Safari 사이트 데이터 삭제 금지.

※ 새 버전으로 앱을 배포하지 않은 오래된 코드에서는 새 백업의 catalogEntries를 읽지 못합니다. 복원 대상도 2.2.3 이상을 사용하세요.
