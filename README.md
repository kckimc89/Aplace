세계 명소대백과 Stage 2.3.7 — 독립 IndexedDB 복원 시험판

부모모드에서 「독립 저장소 복원 시험 (10장)」으로 시작하세요. 원터치 백업 ZIP 한 개를 선택하면 시험용 데이터베이스에 사진을 기록한 뒤 읽어 CRC32 무결성과 명소·순서 정보를 검증합니다.
원래 사진 저장소나 설명·순서에는 쓰지 않습니다.
「전체 사진 독립 복원 시험」은 788장 등 사진 전체를 복제하므로 저장공간 부족/기기 과부하 위험이 있습니다. 여유 공간을 확인하고 이전 백업을 보유한 경우에만 사용하세요.
시험용 독립 데이터베이스는 후속 시험을 위해 남으며, 새로운 시험 전 비웁니다. 시험 성공은 원본 저장소에 실제 반영하는 복원의 무조건 성공을 의미하지 않습니다.
