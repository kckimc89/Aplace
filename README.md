세계 명소대백과 Stage 2.3.5 — ZIP 백업 안전검사판

Stage 2.3.4를 기반으로 원터치 ZIP의 읽기 전용 무손상 검사를 추가했습니다.
부모모드 → 🔍 ZIP 백업 안전검사 → 파일 앱에 저장된 ZIP 선택.
ZIP 중앙 디렉터리, 항목 크기/이름/중복, 각 사진 CRC32, 기본자료의 사진 목록 및 사진 순서/대표사진 기록 존재 여부를 확인합니다.
검사는 웹앱의 사진 저장소를 전혀 변경하지 않습니다.
기존 ZIP 복원 버튼은 유지되지만 사용자 자료에 직접 적용하는 작업이므로 실제 기기 복원은 완전히 분리된 환경에서만 테스트하세요.
앱이 실제 사진과 순서를 정상 복원하는지까지 이 검사만으로 보장하지는 않습니다.
기존 iCloud 백업파일을 삭제하거나 Safari 웹사이트 데이터를 지우지 마세요.
