세계 명소대백과 Stage 2.3.3 — 분할 사진 백업 시험판

기반: Stage 2.3.2, 기존 사진/순서/설명/여행기 IndexedDB 및 localStorage 키 변경 없음.

사용법: 부모모드 → 분할 백업 준비. 기본자료 JSON을 저장한 뒤, 「다음 사진 묶음 저장」을 눌러 사진 25장 단위로 파일을 하나씩 저장합니다. Safari 다운로드 제한을 피하기 위해 사용자가 각 묶음 저장 버튼을 누르도록 했습니다.
사진이 1,162장이면 대략 기본자료 1개와 사진 묶음 47개가 생성됩니다. 모두 동일 폴더에 보관하십시오.
복원: 「백업 합쳐서 복원」에서 기본자료 및 모든 사진 묶음 JSON을 여러 개 선택합니다. 묶음 누락·사진 ID 및 파일명·장수·순서를 검사한 뒤 1개 묶음씩 복원합니다. 작업 중 오류 시 이미 추가된 사진을 지우지 않으며 재실행해 이어 복원할 수 있습니다. 마지막에 명소/여행기/사진 순서를 적용합니다.
기존 단일 JSON 백업 복원도 허용합니다.
주의: 사진 1,000장 이상 아이패드 실제 시험은 아직 완료되지 않았습니다. 다운로드 요청과 실제 파일 저장을 구분하여 파일 앱에서 모든 파일을 직접 확인하세요. 새 백업의 전체 복원 성공 전에는 기존 백업과 앱 데이터를 절대 삭제하지 마세요.
