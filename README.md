# 세계 명소대백과 Stage 1.1 — 사진 자료원 확대

Stage 1.0을 기반으로 **위키미디어 공용 파일명 검색 + Commons 명소별 분류(category) 사진**을 함께 찾습니다. 분류별로 최대 50장의 후보를 확인하며, 전체 후보는 중복 제거 후 최대 90개 표시합니다. 분류는 현재 영어 대표명에서 찾아 맞는 분류 후보를 선택합니다. 분류 검색은 실제 인터넷 환경에 따라 0개일 수 있습니다.

또한 대한민국·중국·일본·프랑스·이탈리아·스페인의 공식 관광 자료원으로 가는 링크를 사진 검색 아래에 제공합니다. **공식 홍보사진을 자동으로 복제/저장하는 기능은 아니며**, 개별 저작권과 사용조건을 확인해야 합니다. 기존 데이터·브라우저 저장키·카드·여행 화면을 변경하지 않습니다.

검증 안내: 오프라인 JavaScript 문법 및 ZIP 검사 수행. 외부 사진 제공처와 iPad Safari 실검색 성공률은 검증되지 않았습니다. 검색 결과가 많더라도 명소 정확성과 라이선스는 부모가 확인하고 선택해야 합니다.

배포: 기존 명소 저장소에 ZIP **내부 전체파일**을 업로드합니다. 캐시 갱신 `?v=11-sources`. 반드시 먼저 백업하세요.
