# 🌍 세계 명소대백과 · Stage 0.2 — 검색엔진 공동선정판

## 이번 단계에서 실제로 추가한 기능
- Stage 0.1의 아름다운 화면, 101개국 국가 목록, 5개국 명소 초안 40개, 기존 사진첩 **그대로 보존**
- 부모모드의 **대표명소 선정·다국어 별칭 공동검토** 패널: 기존 40개를 국가별로 하나씩 위키데이터와 대조
- 위키백과 해당 문서에 연결된 위키데이터 **QID** 우선 조회 (단순 유사 검색어를 확정 식별자로 오인하지 않도록 함)
- QID를 기준으로 한국어·영어·중국어·일본어·프랑스어 이름 및 별칭 수집
- 위키데이터의 나라(P17), 필요하면 행정구역(P131) 상위 정보로 국가 일치 여부 점검
- 국가가 불일치하거나 불명확한 경우 **이름/별칭 승인 버튼 비활성화**. 온라인 검색 실패 시 원본 자료 보존
- 부모가 승인을 눌러야만 기존 이름과 검색 별칭 업데이트. 사진·설명·분류와 즐겨찾기·기존 편집 데이터는 그대로 유지
- 위키데이터 SPARQL로 나라별·종류별 추가 대표명소 후보 발굴. 언어판 연결 수 정렬은 **발굴용 참고 순서이며 인기/대표성 검증 아님**
- 후보를 실제로 조회하여 국가가 일치할 때만 새 항목 입력화면으로 이동. 부모가 지역·분류·설명 확인 후 등록

## 현재 완료되지 않은 작업
- **40개를 이미 전부 온라인 검증한 것은 아닙니다.** 이번 판은 부모가 iPad에서 실제 위키데이터 검색을 실행하고 검토할 수 있게 만든 **엔진 연결판**입니다.
- 현재 파일 안의 40개는 **검색 전 초안**이고, 승인 수는 초기에는 0입니다. 실제 호출 성공 여부는 iPad Safari/GitHub Pages에서 확인이 필요합니다.
- 사진 일치/라이선스·설명 정확성은 별도 검증 대상입니다. 이름/별칭 승인만으로 초록(설명 검증) 판정을 하지 않습니다.
- Wikipedia/Wikidata의 API 제한, 네트워크, SPARQL 장애 시 발굴이 실패할 수 있습니다. 실패해도 원본 자료는 변경되지 않습니다.
- 이번 Stage 0.2는 초기 **5개국 검색 검증 화면**이며 나머지 96개국에 대한 자료는 후속 확장 예정입니다.

## 실행 안내
1. 음식대백과와 **다른 저장소**에 ZIP 내부 파일 전체를 업로드합니다. 기존 Stage 0.1 저장소라면 내용 백업 후 덮어씌웁니다.
2. GitHub Pages 주소 뒤에 `?v=02-selection`을 붙여 캐시를 피합니다.
3. 부모모드를 켜고 **대표이름·만국검색 별칭 공동선정** 패널로 갑니다.
4. 나라를 고르고 기존 명소 옆 `검색해 검토`를 누른 뒤 **국가 일치** 여부와 이름·별칭을 확인하고 승인합니다.
5. 새로운 명소가 필요하다면 상단 **이 나라의 대표명소 후보 발굴**을 눌러 검색해 봅니다.
6. 부모가 이름·별칭·식별번호를 수동 수정하면 이전 이름 검토 표시는 자동으로 해제합니다. 동일 QID 중복 등록은 방지합니다.
7. 부모모드의 백업/복원 포맷과 저장키는 Stage 0.1과 동일하므로 기존 편집 자료가 유지되도록 설계했습니다. 배포 전 백업을 권장합니다.
