# 세계 명소대백과 Stage 0.8 — 사진 중심 명소 카드 정리

- Stage 0.7의 나라별 사진 여행과 마무리 모자이크 유지
- 프랑스 8개 명소의 공통적인 권유 문장을 장소별 구체 정보로 교체
- 카드 사진은 원래 비율로 크게 보이도록 정리
- `이전 사진 / 다음 사진` 버튼 삭제. 작은 사진첩을 직접 선택
- `다른 사진 찾아보기`를 대표사진 위 오른쪽으로 배치
- `등록된 사진첩` 안내와 상세 카드의 별칭 나열 삭제 (검색용 데이터는 유지)
- 상세 카드 아래에 `이전 명소 / 다음 명소` 버튼 추가: 같은 나라의 등록 순서에 따라 이동
- 부모의 직접 수정 설명과 기존 데이터 구조 유지
