# 세계 명소대백과 Stage 0.6 — 사진 여행 마무리 및 카드 집중판

- Stage 0.5 화면, 기존 자료, 검색, 부모모드·백업 유지
- 몽생미셸은 확보된 사진이 3장일 때 3장 모두 각각 소개하며 세 번째 장면에 갯벌·조수 변화 설명 추가
- 개별 명소 상세에서 별도 음성 가이드 패널 제거, 큰 사진·사진첩·요약설명 중심으로 재정리
- 프랑스 대표명소 8개 카드에 특징을 살린 요약설명 보강(사용자가 직접 수정한 설명은 우선)
- 나라 사진 여행을 끝내면 짧은 복습 안내를 읽고 해당 국가의 명소 이름표로 돌아감
- 음성 실패 시 마무리 화면의 '명소 이름표 보기' 버튼 사용 가능
- 온라인 사진은 출처 검증 전 참고자료이며, 세 번째 사진이 실제 확보되지 않은 경우 임의의 다른 사진으로 대체하지 않음
