# 세계 명소대백과 Stage 0.5 — 대표명소 전체를 둘러보는 나라 사진 여행

- Stage 0.4 화면, 나라별 이름표, 사진첩, 검색·편집·백업, 기존 저장키 유지
- 프랑스 등록 명소 8개 **모두** 여행에 포함. 대한민국도 등록된 명소 전체를 포함
- 기존 확인된 사진 재사용. 사진 부족 시 해당 명소 Wikipedia 대표사진을 온라인에서 임시 조회(검토 전 표시)
- 사진이 없는 명소도 여행에서 누락하지 않고 명소명·설명 표시. 다른 명소의 사진을 잘못 대신 보여주지 않음
- 사진이 2장 이상이면 짧은 원고 2개를 사진에 맞춰 순서대로 재생. 사진 1장일 때는 한 번의 설명으로 병합
- 기존 iPad 기본 음성 사용, 관광가이드 말투를 유지하며 8개 프랑스 명소별 전용 원고 작성
- 실제 iPad Safari 네트워크·음성 재생은 사용자 기기에서 검증 필요
- 새로운 명소자료/온라인 사진의 정확성은 자동으로 승인하지 않음

GitHub 명소대백과 저장소에 ZIP 내부 파일 전체를 업로드하고 `?v=05-allplaces`로 열어 주세요. 음식대백과 저장소에는 업로드하지 마세요.
